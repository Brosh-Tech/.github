# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report privately by email to **info@broshtech.com** with:

- A description of the issue and its impact
- Steps to reproduce
- Affected repository and version, if known

We will acknowledge your report as soon as reasonably possible and keep you updated on the fix.

Please give us reasonable time to resolve the issue before any public disclosure.
