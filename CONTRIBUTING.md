# Contributing

Thanks for your interest in contributing to Broshtech projects.

## Workflow

1. Open an issue describing the bug or feature before starting large changes.
2. Fork the repository (external contributors) or create a branch (team members).
3. Use descriptive branch names: `feature/...`, `fix/...`, `chore/...`.
4. Keep changes focused and small; add or update tests where relevant.
5. Open a pull request describing what changed and why.
6. Address review feedback. A maintainer merges once approved and checks pass.

## Standards

- Follow the code style and linting rules of the repository.
- Do not commit secrets, `.env` files or credentials.
- Update documentation when behaviour changes.
